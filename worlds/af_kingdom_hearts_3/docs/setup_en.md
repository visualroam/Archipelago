# AF Kingdom Hearts 3 – Setup

Manual world: no game mod. Items are permissions:

- **Progressive World**: worlds open in story order (Olympus is open from the start). Do not enter a world before you have enough.
- **Keyblade: …** / **Magic: …** / **Attraction Flow** / **Links**: only use them once you have the item (Kingdom Key is always allowed).
- **Traps** are rules for the streamer (e.g. Kingdom Key only until the next save point).

Checks are marked by moderators in the AF dashboard. Collect all worlds and enough Heart Pieces, then defeat Master Xehanort.
